---
description: 捉え方を複数出させ、重なりを見て仲間分けし、担当の割り当て案を作る
argument-hint: [案の数（既定 5）]
---
実装の前に、問題の捉え方を並べます。あなたは conductor です。

1. `framer` サブエージェントを ${1:-5} 個、**並列に**呼ぶ。各回に「既に出た捉え方の名前」を渡さず、独立に出させる。
2. 出てきた案を、言い換え・主要な自由度で仲間分けする。同じ仲間に 2 案以上入ったら、その仲間を伝えたうえで `framer` を追加で呼び、重ならない案を出させる（最大 2 周）。
3. 仲間ごとに「担当の割り当て表」を作る: 名前 / 観点 / 起点 / 仮説 / 最小の実験 / 続ける条件。
4. 表を人間に示し、承認された行から `ahc lane new <名前> --angle ... --hypothesis ... --experiment ... --continue-if ...` と `ahc lane start <名前> --agent claude|codex` を実行する。
5. 判断を `ahc decide` に残す。
