# beam6（beam4 からの差分）
- 1 区間は「歩く → 転移 → 歩く → 転移 → 歩く」まで（深さ 2）。2 回目の転移の前にも歩けるので、置く魔法陣 2 つの位置をそれぞれ選べる。
- 出発点の候補: そのまま / g に直接着く点 / 次の区間の中点 / その中点を「追加費用なしの箱」に寄せた点。
- 評価 = 実コスト + 先読み。先読みは魔法陣ごとに分解できる形
  F(セル) = -max_j 0.9^j · max(0, D_j - (2·|セル-中点_j| + 1))（先の 12 区間）を各区間で盤面全体に前計算し、表引き 3 回で評価。
- 速くなった分ビーム幅が広がる（終盤で 1 万〜数万）。
