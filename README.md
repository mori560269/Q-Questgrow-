# TEDxQuestgrow 2026 イベントアプリ

テーマパーク公式アプリのような体験をめざした、TEDx イベント向けのモバイルファースト Web アプリです。

## 機能

| 領域 | できること | 主なファイル |
|---|---|---|
| 予約 | トーク・ワークショップ・ツアー・交流会の予約／キャンセル、時間が重なる予約のブロック、満席時のキャンセル待ちと自動繰り上げ、QR チケット | `src/lib/reservation.ts`, `src/pages/Programs.tsx`, `src/pages/MyPlan.tsx` |
| 会場マップ | SVG の会場図、エリア詳細、最短ルート（ダイクストラ法）、段差を避けるルート、混雑ヒートマップ、展示ブース一覧 | `src/lib/route.ts`, `src/pages/Map.tsx` |
| 交流 | 関心と目的にもとづくマッチング（相性スコアと理由を表示）、つながりリクエスト、1対1チャット、会話のきっかけ候補 | `src/lib/matching.ts`, `src/pages/Connect.tsx`, `src/pages/Chat.tsx` |
| 自然言語処理 | **AI コンシェルジュ**（Claude、ストリーミング）、自然文でのプログラム検索（「午後のAIのワークショップ」など）、**問い合わせの自動振り分け**（カテゴリ・緊急度・返信案）、**日英アナウンス文の自動作成** | `server/`, `src/lib/nlp.ts`, `src/pages/Assistant.tsx` |
| 当日運営 | 進行管理（遅延の設定と後続への波及、中止、入場数カウント）、受付チェックイン、緊急度順の問い合わせ受信箱、お知らせ配信、エリアごとの混雑度更新、KPI 表示 | `src/pages/Ops.tsx` |

AI の回答に `[[w1]]` のようなセッション ID が含まれると、アプリ側で予約ボタン付きのカードとして表示します。`[[map:food]]` はマップへのリンクになります。

## 起動方法

```bash
npm install
cp .env.example .env   # Claude を使う場合は ANTHROPIC_API_KEY を設定
npm run dev            # http://localhost:5173 （API は :8787）
```

- **API キーがなくても全機能が動きます。** その場合、AI 機能はローカルのルールベース NLP（文字バイグラム類似度と辞書）で応答します。
- 運営機能を試すには、ホーム左上のアバターからプロフィールを開き、モードを「運営スタッフ」に切り替えます。
- 来場者用と運営用を別タブで開くと、配信・遅延・問い合わせがリアルタイムに同期します（BroadcastChannel を使用）。
- 運営ダッシュボードの時刻スライダーで当日の時刻を動かすと、「いま開催中」「次の予定」などの表示を確認できます。

```bash
npm test            # ユニットテスト（予約・ルート・マッチング・NLP）
npm run typecheck
npm run build && npm start   # 本番ビルドを Express から配信
```

## PWA（ホーム画面に追加）

- ホーム画面に追加すると、ブラウザのバーなしでアプリとして起動します。マニフェストのショートカットとして「チケット」「マップ」「AIに聞く」も登録されます。
- Android や PC の Chrome / Edge では、ホームに「ホーム画面に追加」カードが出ます。iPhone では「共有 →『ホーム画面に追加』」の手順を案内します。
- **オフラインでも起動します。** 一度開いた後は、電波が届かなくてもチケットの QR・予約一覧・マップ・プログラムを表示できます。AI コンシェルジュはローカル応答に切り替わります。オフライン中は画面上部に帯を表示します。
- 新しいバージョンをデプロイすると「新しいバージョンがあります［更新］」の帯が出ます。
- Service Worker（`public/sw.js`）は本番ビルドでだけ登録されます。動作を確認するときは `npm run build && npm start` を使ってください。公開には HTTPS が必要です（localhost は除く）。
- HTML はネットワークを優先し、ハッシュ付きのビルド済みファイルはキャッシュを優先します。そのため、通常のデプロイで `sw.js` を書き換える必要はありません。キャッシュの方針を変えたときだけ、`sw.js` の `VERSION` を上げてください。古いキャッシュは自動で削除されます。

## 構成

```
server/            Express + Anthropic SDK（/api/chat, /api/triage, /api/announce）
src/data/event.ts  イベントのマスターデータ（プログラム・登壇者・会場・FAQ）
src/lib/           予約、ルート検索、マッチング、NLP、状態管理などのロジック
src/pages/         各画面
tests/             ユニットテスト
```

- モデルは `claude-opus-5-5` を使います。拒否が返った場合は、サーバー側で推奨モデルへ自動的にフォールバックします（`fallbacks: "default"`）。
- イベント情報は system プロンプトに固定してプロンプトキャッシュを効かせています。現在時刻・遅延・予約状況など変化する情報は、会話の末尾に system メッセージとして渡します。
