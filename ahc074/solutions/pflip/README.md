# pflip（起点: free2 からの差分）

## 駐車（列の先頭でポートの範囲をまとめて合わせる）
列 c の上掛けはポート 0..c で不透明。列 c の先頭 h を「列 j+1 の区画の先頭の直前」（列 ≤j より下、列 j+1..c−1 より上）へ差し込むと、
ポート (j,c] がまとめて h の色になる（列 ≤j の先頭は上にあって (j,c] では穴、列 >c は下）。
h が (j,c] で目標と一致すれば、1 手で (j,c) の不一致をまとめて直せる。
列 c の要素の ord_ での順は変わらない（h は列 c の論理的な先頭のまま）ので、交互の色・portStack・portFlip はそのまま使える。
状態は parkA[k]（駐車中なら区間の下端 j、でなければ −2。mv で消え、案 X/Y の巻き戻しで一緒に戻す）。

1. fixPorts(lo, tgt): ポート lo.. を合わせる。
   - 駐車中の物: 区間が目標と一致すれば残す。違えば c の降順で、ポート c が合えば新しい区間へ差し直し（得 ≥ PT2=1）、
     そうでなければ列 c へ戻す（先頭／末尾を目標の色で選ぶ。1 手でポート c も合う）。
   - 新しい駐車: c の降順で、列 c の先頭（ポート c の色が違えば 2 番目 = 反転後の先頭）が目標と一致する下向きの連 (j,c] を伸ばし、
     その中の実際の不一致の数 ≥ PT=2 なら（必要なら c を反転してから）駐車。
   - 残りの不一致を反転。
2. 案 Y: 浮いた上掛けを戻す → fixPorts(0) → 地紙。案 X: 列 >p の浮いた上掛けを戻す → ポート p を覆う駐車（列 >p、j<p）を戻す
   → 深さぶん反転 → 上掛けを出す → fixPorts(p+1)。
3. 浮いた上掛けも、ポート c で目標と合い、連の得 ≥ PT3=1 なら列へ戻す代わりに駐車（同じ 1 手）。
4. NPORT 30 → 40（反転が安くなったため。36〜42 は平ら）。free2 の fc の配列を 64 に。

不変条件: 浮いた上掛けの列と駐車中の列は重ならない／駐車の区間どうしは重ならない／差し込み先は保管域（1 マス紙・地紙より下）。
