# zcanon（起点: free4 からの差分）

1. 列の割り当て（COLSW の入れ替えの山登り）の目的 fc を、ポートの先頭の実際の色の分布に合わせて作り直す（ZR=12 回、反復の総数 COLSW 200000 → 600000）。
   - ポート q の先頭の色は「最後にポート q を書いた注文の商品」の色。書くのは上掛けなしの商品（Y はポートを全部書く）と、列 p' < q の上掛けの商品（X は q > p' だけ書く）。
   - 1 回目は従来どおり全商品の黒の割合、2 回目からは今の割り当てでの書き手の黒の割合 bq を使い、fc[u][p] = Σ_{q>p} (u_q ? 1−bq : bq)。
   - 「後ろのポートを共通の基準の色 Z に寄せる」案の受け身の部分（自己無撞着版）。Z を能動的に保つ（隠れた先頭を直す）のは机上で損（notes.md 実験1）。
2. 手元専用: -DSTAT に案 X の後ろのポートの内訳（直前が X か Y か、不一致数、直しの手数）。
