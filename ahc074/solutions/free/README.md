# free（port2 からの差分）
1. 上掛けを割り当てる商品: ポート窓の中の黒が多い商品から順に（上掛けなしの手数 ≒ 非ポート窓の白の数なので、白が多い＝ポートに黒が多い商品ほど上掛けの得が大きい）。ポートの色の枠は維持し、枠の空きが多いポートへ。
2. ポート窓の位置: 上掛けのない商品（下位 116 個）のポート内の黒の合計が最小になるよう、窓の入れ替えの山登りで 13 窓を選ぶ。内部では列を並べ替えて 0..12 をポートとし、設計の出力時に戻す。
3. 上掛けの差し戻しを遅らせる: 上げた上掛けは巡回の交互列から抜いた位置のままなので、一番上にあってもそのポート列の先頭として扱う。次も上掛けの注文なら戻さない（色が違えば反転＝列の末尾へ、の 1 手）。地紙で直す注文では、浮いた上掛けを目標の色に合う側（列の先頭の前／末尾の後ろ）へ戻す（反転を兼ねる）。案 X（上掛け）と Y（地紙）は実際に両方の手を作り、手数の少ない方を採る。
4. 地紙の下へ送る黒紙の差し込み位置: 上掛けなしの商品での黒の頻度の高い順に並ぶ位置へ（白になりやすい窓ほど深く。地紙は一番深い黒の直下まで下がるので、その下の白はただになる）。上掛けより上には置かない。
