# paint（起点: free4 からの差分）

1. fixPortsDP（gDir=4）を fixPortsLA の案の 9 番目に追加（NALT 8→9）。
   ポート lo.. を区間に分ける DP。区間 (b,c] の候補は列 c の先頭（1 手）・2 番目（反転 + 駐車で 2 手）、
   既存の駐車（同じ b なら残す -1 手、別の b へ差し直し 0 手。未使用なら戻す 1 手は全案共通）、
   案 Y では浮いた上掛けも同じ扱い（LOOSEDP=1。浮いた紙の区間は他の駐車の列 c' を含めない: 戻せなくなるため）。
   単独のポートは不一致なら反転 1 手。区間の費用に DMU2=0.1 × 長さを足す。
   動かす順は「見えている物から」（戻す → 差し直し → 新しい駐車 → 反転）。
2. 案の選び方: 今の手数 + MU2=0.1 × Σ(終わりの駐車の区間の長さ)（長い駐車は次の注文で戻しが要る見込み）。
3. 手元専用: -DASTAT（案ごとの手数の合計）、LAM>0 の先読みは serve() 全体で評価（evalNext）。既定では無効。
