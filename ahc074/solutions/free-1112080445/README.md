# free（起点: mground からの差分）
mground（部分地紙 2 枚 + 閾値の全探索、NPORT 12）に、port2 上で効いた 4 つの変更を載せ直したもの。
1. 上掛けを割り当てる商品: ポート窓の中の黒が多い商品から順に（上掛けなしの手数 ≒ 非ポート窓の白の数なので、ポートに黒が多い商品ほど上掛けの得が大きい）。ポートの色の枠は維持し、枠の空きが多いポートへ。
2. ポート窓の位置: 上掛けのない商品（下位 P-上掛け数 個）のポート内の黒の合計が最小になるよう、窓の入れ替えの山登り 2 万回で 12 窓を選ぶ。内部では列を並べ替えて 0..11 をポートとし、設計の出力時に戻す。
3. 上掛けの差し戻しを遅らせる: 上げた上掛けは巡回の交互列から抜いた位置のままなので、一番上にあってもそのポート列の先頭として扱う。次も上掛けの注文なら戻さない（色が違えば反転＝列の末尾へ、の 1 手）。地紙で直す注文では、浮いた上掛け（どの 1 マス紙・地紙よりも上にある上掛け）を目標の色に合う側（列の先頭の前／末尾の後ろ）へ戻す（反転を兼ねる）。案 X（上掛け）と Y（地紙）は実際に両方の手を作り、手数の少ない方を採る。
4. 白にする黒紙を地紙の下へ送るとき（mground の `mv(L[i], posOf(G))` の 2 か所 → `sinkPix`）: 同じグループの黒紙が「上掛けなし商品での黒の頻度」の降順になる位置へ。上掛けより下には置かない（置くと地紙が上掛けの下へ下がり E になる）。

select（50件）: mground 20616.4 → 19885.9（+3.67%、z=15.7、50勝0敗）
dev --fresh（150件）: mground 20574 → 19926.9（+3.25%、z=20.2、144勝6敗）、誤り 0、時間 max 271ms
ablation（select、本版比）: 4 を外す -0.48%（z=-13.8）、NPORT 13 -0.23%（差なし）、NPORT 11 -0.42%、MG 3 -0.57%。
