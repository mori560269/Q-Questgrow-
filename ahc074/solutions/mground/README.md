## 起点からの差分

- 各グループの地紙の位置（閾値 t = 地紙より上に残す自グループの黒紙の数）を全探索で選ぶ。
  手数 = [地紙を動かすか] + (t より上の要白) + (t より下の要黒)。
  - 地紙より下の紙は見えないので、地紙より下に要黒があれば t はその一番深いものより下（1 手）か、
    「一番深い要黒の直下まで下げてから t へ上げる」（2 手）。
  - 上げるとき: 間の要黒を一番上へ、t より上の要白を地紙の直下へ移してから地紙を上げる。
  - 地紙が見えない（自グループの黒紙が全部上）で動かせない手は候補から外す。
- 上掛けを使うかの比較（案 X と Y）で、Y の手数を「違う窓の数」から上の正確な手数に変えた。
