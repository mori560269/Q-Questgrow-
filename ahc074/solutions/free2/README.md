# free2（起点: nest からの差分）
1. 上掛けの列の割り当てを入れ替えの山登りで直す（COLSW=200000）: 列 p の上掛けを出すと直すのはポート q>p だけなので、
   商品 u を列 p に置いたときの直しの期待数 fc[u][p] = Σ_{q>p} P(前の商品のポート q の色 ≠ u_q)（前の商品は全商品で一様、窓 q の黒の商品数から計算）。
   2 つの列の商品を入れ替える（各ポートの色の枠が保たれる組だけ）山登りで Σ fc を最小に。
2. 上掛けを付ける商品を起動時の模擬計算で選ぶ（SIMIT=3、3000 歩、2 歩ごとに標本）:
   設計を組み立て（build）、乱数の注文で実際の方針（serve）を流し、各状態で全商品の「案 Y の見積もり =
   地紙側の手数（閾値の全探索、高速版 groundCostAll）+ 3 × いまの表示とのポートの不一致数」を平均。大きい商品から上掛けを割り当て直し、3 回繰り返す。
   ポート窓の選択は nest のまま（初期の優先度 = ポート内の黒の数で選んだ集合に対して）。
3. 高速化: portStack(q).front() → portFront(q)。
